Aether Studio

A modern Flask portfolio website built with responsive design, database integration and admin dashboard.

Live Demo GitHub

Tech Stack

Python Flask HTML CSS JavaScript SQLite

Key Features

  • Responsive multi-page Flask website
  • SQLite powered Contact form with SQLite database
  • Secure admin login systems
  • Admin dashboard to manage visitor messages
  • Smooth scrolling animations
  • Portfolio-ready project structure

What I Learned

Building Aether Studio taught me how to turn an idea into a complete real-world website. I learned how frontend, backend, databases and authentication work together to create a functional web application. More importantly I learned how to structure a project, solve practical problems and think beyond just writing code and think like a user while working as a developer.

Challenges Faced

  • Designing a clean and responsive user interface.
  • Managing visitor messages using SQLite.
  • Building a secure admin login flow.
  • Keeping the project modular and easy to maintain.

Project Outcome

Aether Studio became my first complete portfolio website and my first end-to-end web development project. It represents the point where I moved from writing Python programs to building complete website with a real backend, database and user interaction. This project also became the foundation for learning how real web applications are structured and deployed.
