📝 Notes App

A command-line Python application that allows users to create, edit, search and manage notes efficiently while practicing clean function-based programming.

Live Demo GitHub

Tech Stack

Python Flask HTML CSS SQLite

Key Features

  • Add notes
  • Edit notes
  • Delete notes
  • Search notes
  • Count notes
  • Case-insensitive operations

What I Learned

This project strengthened my understanding of Python functions, lists, loops, string manipultion and writing modular code. It also taught me how to think about user experience even in a command-line application.

Challenges Faced

  • Making search case-insensitive
  • Editing only the correct note
  • Keeping functions
  • Avoiding repititive code

Project Outcome

Notes App became one of my first complete projects and helped build the programming foundation that later made learning Flask much easier.
